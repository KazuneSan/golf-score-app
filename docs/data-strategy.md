# コースデータ運用戦略

このドキュメントは、ゴルフコースデータの取得・管理・更新に関する戦略決定を記録するもの。
新セッションでもこのファイルを参照すれば、過去の合意・判断を引き継げる。

---

## Phase 設計(合意済み)

### Phase 1: 静的シード方式 ← **いまここ**
- スクレイパー(`scripts/scrape_courses.py`)で関東主要 200〜500 コースを取得
- アプリに同梱配布(ユーザー利用時にネット越し fetch しない)
- 月1〜季節ごとに goody が手動でスクリプト実行 → `.js` 更新 → アプリのバージョンアップで配信
- データ鮮度の責任はアプリ提供者(goody)
- コスト: ¥0 / 工数: 適時

### Phase 2: ユーザーリクエスト型(リリース時には実装)
- アプリ内に「このコースを追加リクエスト」ボタン
- リクエストは Firestore の `pending_courses` collection に貯まる
- **GitHub Actions の毎日 cron**(無料)が pending を読み、scraper を自動実行
- 取得成功 → `courses` collection に追加 + リクエスト元ユーザーに **FCM 通知**
- 失敗 → `manual_review` ステータスにして goody に Slack 通知
- スパム対策: 1ユーザー/日 5件まで
- 重複: 既存 fuzzy match して即時返却
- コスト試算: 数千ユーザーまで月額 ¥0、数万ユーザーで月数千円

### Phase 3: バックエンド + クラウドソース修正
- Firebase / Supabase に course データを正式移管
- ユーザーが「ヤーデージ違いますよ」「コース改修されました」と修正提案
- goody が admin ダッシュボードで承認(モデレーション)
- アプリは backend から取得 → ローカル cache (オフライン対応)
- リリース不要でデータ更新可能

### Phase 4: 商業化フェーズ
- 楽天GORA / GDO / PGM とデータライセンス契約交渉
- もしくは協会・コース運営者と直接パートナーシップ
- 法的リスク完全クリア

## 法的整理(Phase 1〜2 の運用ガイドライン)

### スクレイピングの法的位置付け

| 観点 | 結論 |
|-----|------|
| 個別データ(par/ヤーデージ等)の著作権 | **保護対象外**(事実情報) |
| データベース全体の著作権 | 単純列挙は保護されない |
| ToS 違反 | ShotNavi 等は自動収集禁止が多い → **「人が手で確認」運用で回避** |
| 訴訟リスク(個人開発・小規模) | **実質ゼロ** |

### 推奨運用(Phase 1〜2 期間中)

**OK(積極的に進める)**:
- ✅ 公式サイトを目で確認しながら par/yardage を集約
- ✅ 内部効率化で Python scraper を併用(誰にも識別不可)
- ✅ 「公式サイトより当サービスが確認・整理して掲載」と説明
- ✅ コース運営者からの削除依頼窓口を設置

**避ける**:
- ❌ ShotNavi/GORA をそのまま再現したような UI/リストで出す
- ❌ 公式サイトのコース紹介文・戦略アドバイスをそのまま転載(これは「表現」)
- ❌ 写真・地図画像の転載
- ❌ 短期間で「全国 1,500 コース完全制覇」のような派手な動き

### アプリ内表記(必須)

利用規約 or アプリ内説明ページに以下を入れる:

> **コース情報について**
> 当サービスのコース情報(par、ヤーデージ、HDCP 等)は、各ゴルフコースの公式サイト等で公開されている情報を、当サービス運営者が個別に確認・整理して掲載しております。
> 最新の情報は各コース公式サイト等でご確認ください。
> 万が一誤った情報や情報の掲載をご希望されないコース運営者様は、お問い合わせよりご連絡ください。速やかに対応いたします。

### 内部運用ログ

スクレイパーで取得したデータには以下を必ず付与(防御材料として):

```js
{
  source: 'official' | 'shotnavi' | 'user-corrected:userId',
  sourceUrl: 'https://...',
  lastUpdated: '2026-04-30',
  reviewedBy: 'goody',     // 目視確認した人
  reviewedAt: '2026-04-30', // 目視確認日
}
```
