v2 からの変更: 「ティーショットで OB を打つ」(症状) と「持ち玉が決まっていない」(原因) が同列にあった混乱を解消。 1つの症状に対し複数の原因候補を並べ、各原因に達成基準を紐付ける形に再構成。 ユーザーは「自分の症状はこれ → 原因はどれか考えて選ぶ → その原因の達成基準を満たす」というフローで使う。

v3 追加: 「達成基準 (練習)」に加え「ラウンド評価基準」を追加。 練習場でクリアしても、コースで発揮されるまでが本当の解決。 ラウンド評価基準は練習ラウンド (または通常ラウンドの記録) で直近 3〜5R の統計で判定する。
