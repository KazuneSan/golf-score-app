# Drill Animation Spec — テンプレート

新しいドリルアニメーションを依頼/実装する **前に必ずこのテンプレートを埋める**。
埋まらない欄があるなら、設計が曖昧。コードに行かない。

GateDrillAnimation がそのまま参照実装。新ドリルもこの粒度・トンマナを目標にする。

---

## 1. アイデンティティ

| 項目        | 例                                              |
|-------------|------------------------------------------------|
| **名称**    | Gate Drill / ゲートドリル                       |
| **カテゴリ** | Putting (1m パット)                             |
| **練習時間** | 5 分                                            |
| **必要道具** | ティー × 2、ボール 5球                          |

## 2. 視点 / カメラ

ひとつ(または2つ)を選ぶ:

- [ ] **Top-down (俯瞰)** — ボール/クラブ/ものの位置関係が一望できる
- [ ] **Setup (セットアップ)** — ボール後方、プレイヤー目線
- [ ] **Side** — 真横、ターゲットラインが水平
- [ ] **3/4 isometric**

> パッティングドリルは Top-down が最強。フェース・軌道・余白がすべて読める。

## 3. プロップ (ボール・クラブ以外で場に置くもの)

| 物            | 位置                          | 役割                          |
|---------------|------------------------------|-------------------------------|
| 例: ティー × 2 | ボールの 10cm 前、ボール幅+α  | ゲート (ボール直径+数 mm)     |
| (カップ?)     | —                             | このドリルでは不要              |

## 4. ステップ (キャプション、最大 4 ビート)

3〜4 ビートに分けるとアニメも文章も読みやすい。

| # | キャプション (日本語)                       | 秒数            |
|---|---------------------------------------------|-----------------|
| 0 | ボールの 10cm 先に ティー2本でゲートをつくる  | 0.0 – 2.6       |
| 1 | ボールをセットする                           | 2.6 – 4.4       |
| 2 | スクエアフェースで 真っ直ぐ振る                | 4.4 – 5.6       |
| 3 | ティーに触れず 5回連続で通過 → クリア         | 5.6 – 11        |

合計 11 秒前後を目標。1ビート最低 1.5 秒(日本語 8 文字/秒で読めるように)。

## 5. 成功条件

ユーザーが見て一発で覚える1行:

> 例: **ティーに触れずに 5回連続で通過 → クリア**

| 項目        | 値             |
|-------------|----------------|
| ゴール回数  | 5              |
| 失格条件    | ティーを倒す    |
| 許容範囲    | 触れるだけはOK |

## 6. 視覚的に絶対に伝えるべき (2〜3 個)

初見の視聴者が一目で理解しないといけないこと:

- [ ] 10 cm の距離関係
- [ ] 「ボールがギリギリ通る幅」のクリアランス感
- [ ] ボールが転がること(球面が回転する表現)
- [ ] 通過の瞬間がはっきり分かる
- [ ] 目標: N回連続(HUD で常時表示)

## 7. 避けるべき表現

- ❌ 製図記号だらけで冷たい
- ❌ 雑誌風の派手な色面
- ❌ 緑の芝テクスチャ (モバイル UI の cream カードに浮く)
- ❌ 横から見たティー記号 (俯瞰視点と整合しない)
- ❌ ブランドロゴ (許諾なしの Titleist 等は使わない)

## 8. ループの長さ / テンポ

| 項目         | 値                              |
|--------------|--------------------------------|
| 持続時間      | 11 秒                           |
| 表現         | 1回見せた後ループ                |
| リセット動作  | t > 10.4 s でクロスフェード      |

## 9. ビジュアル言語 (再発明禁止)

**`src/components/drillPrimitives.js`** のプリミティブを使う:

- `GolfBallTopDown` — 白球 + 回転ストライプ
- `GolfTee` — ティー俯瞰アイコン
- `MalletPutter` — センターシャフトのマレット、右利き既定
- `DimensionLabel` — "10cm" 黒ピル + 矢印
- `StreakHUD` — "GOAL · N回連続" + ドット
- `CheckBadge` — 緑 ✓ (成功瞬間)
- `CaptionOverlay` — 動画下のダークバー (STEP n/N + 文)
- `useDrillTimeline` — RAF タイムライン
- `easing`, `clamp`, `DEFAULT_THEME`, `CANVAS_W`, `CANVAS_H`

**新しいプロップが必要なら(カップ/フープ/アライメントスティック/定規等)、必ず drillPrimitives.js に追加。drill 固有ファイルには書かない。** 同じ視覚言語(cream fill + ink outline + subtle shadow)を必ず守る。

## 10. キャンバス

全ドリル **viewBox `0 0 720 800`** を使う。座標が共有されることで
StreakHUD など W/H 依存のプリミティブがレイアウト崩れせずに使い回せる。

コンテナ側 (DrillDetailScreen.diagramBody) は drill 名で aspectRatio を
切り替える既定パターンを使う:

```jsx
<View style={[
  styles.diagramBody,
  drill.setup === '[name]' && { aspectRatio: 720 / 800 },
]}>
```

これを忘れると Web プレビューで詰めた絵がカードの左右に余白で吸われる。

## 11. 記入例 (次のドリル)

```
名称:           距離感ドリル / Distance Drill
視点:           Top-down
プロップ:       カップ(実物)、30/60/90 cm の参照ドット
ステップ:
  0. カップから 30/60/90 cm の地点にマーカーを置く
  1. それぞれの距離でストロークを変える練習
  2. 3 球連続でカップから ±10 cm 以内に止める
  3. 3 距離 × 3 球連続 = クリア
成功:           全 9 球が ±10 cm 以内
必須視覚:       距離の違い、振り幅の違い、許容範囲
回避:           実距離の数字を大きく出しすぎる(密度過剰)
所要:           12 秒
新プリミティブ: Cup, ReferenceDot
```

これを埋めずに実装に入った瞬間に品質が落ちる。
