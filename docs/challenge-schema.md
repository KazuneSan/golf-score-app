# 課題マスタ v2 スキーマ

旧 CSV (`challenges-master.csv`) の問題を解決するために再設計した表構造。
このスキーマで `challenges-v2.csv` を埋める。

---

## 設計原則

このアプリの価値は「**スイングの仕方を教えない**」「**自分が解決すべき課題を可視化＆管理**」の2点。
表は以下の3つの問いに答えられないといけない:

1. **その課題は自分にあるか？** (発見)
2. **練習でクリアしたといえる基準は？** (練習解決)
3. **コースでクリアしたといえる基準は？** (コース解決)

旧 CSV は (2) しか書いていなかった。v2 は (1)(2)(3) すべて埋める。

## 列定義 (21 列)

### A. 識別 (3 列)

| # | 列名 | 型 | 必須 | 例 |
|---|------|-----|-----|-----|
| 1 | `id` | string (kebab) | ◯ | `tee-ob`, `putt-short-1m` |
| 2 | `title` | string | ◯ | ティーショットで OB を打つ |
| 3 | `category` | enum | ◯ | Tee / Approach / Iron / Putt / Bunker / Mgmt / Mental |

### B. ターゲット (2 列)

| # | 列名 | 型 | 必須 | 例 |
|---|------|-----|-----|-----|
| 4 | `targets` | enum多選 (`,`区切) | ◯ | `100切り,90切り` |
| 5 | `priority` | enum | ◯ | `high` / `mid` / `low` (推定 SG ベース) |

### C. 課題の性質 (2 列)

| # | 列名 | 型 | 必須 | 説明 |
|---|------|-----|-----|------|
| 6 | `type` | enum | ◯ | `skill` (技術) / `mgmt` (戦略) / `mental` / `knowledge` |
| 7 | `completion` | enum | ◯ | `one-shot` (1回考えれば終わり) / `continuous` (継続観察) |

### D. 発見 (3 列) ← 旧表に完全欠落

| # | 列名 | 型 | 必須 | 例 |
|---|------|-----|-----|-----|
| 8 | `self_check` | string (質問文) | ◯ | 「直近5R で OB が平均2個以上ありましたか？」 |
| 9 | `auto_detect` | string (式) | △ | `recent5.avg_ob >= 2` |
| 10 | `required_metrics` | string (`,`区切) | △ | `ob_count_per_round` |

### E. 練習解決基準 (4 列)

| # | 列名 | 型 | 必須 | 例 |
|---|------|-----|-----|-----|
| 11 | `practice_env` | enum多選 | ◯ | `home,putter-mat` / `range` / `simulator` / `course-only` |
| 12 | `practice_lv3` | string | △ | 持ち玉で 左右±20yd以内 10/10 |
| 13 | `practice_lv2` | string | △ | 10/7 |
| 14 | `practice_lv1` | string | △ | 10/5 |

`course-only` の場合は practice_lv* 空欄でよい。

### F. コース解決基準 (2 列) ← v2 の最重要追加

| # | 列名 | 型 | 必須 | 例 |
|---|------|-----|-----|-----|
| 15 | `course_criteria` | string | ◯ | OB 平均 0.5個以下 |
| 16 | `course_rounds` | int | ◯ | 3 (直近何ラウンドで判定) |

### G. 解決手段 (3 列)

| # | 列名 | 型 | 必須 | 例 |
|---|------|-----|-----|-----|
| 17 | `drill_ids` | string (`,`区切) | △ | `gate-drill,straight-1m` |
| 18 | `video_url` | URL | △ | (YouTube 等の外部リンク) |
| 19 | `prerequisite_ids` | string (`,`区切) | △ | `tee-direction` |

### H. メタ (2 列)

| # | 列名 | 型 | 必須 | 説明 |
|---|------|-----|-----|------|
| 20 | `notes` | string | | 旧表の備考相当 |
| 21 | `comment` | string | | 開発者コメント (UI に出さない) |

## 課題の網羅範囲

以下のチェックリストで「全課題が出揃ったか」を判定する:

### 100切り (Phase 1 必須)
- [ ] ドライバー OB
- [ ] アプローチでダフる
- [ ] アプローチでトップ
- [ ] バンカーで一発で出ない
- [ ] 3パットを打つ
- [ ] 1m パットを外す
- [ ] ボギーオン率が低い (マネジメント)
- [ ] ハザード/OB 認知不足 (マネジメント)
- [ ] 番手選択ミス (マネジメント)

### 90切り
- [ ] パーオン率が低い (ティー距離 / セカンド精度)
- [ ] 30y 以内アプローチで寄らない
- [ ] ティーショットの方向性
- [ ] 100Y ショートアイアン
- [ ] グリーン周りのライ判断
- [ ] ティーボックスでの戦略選択
- [ ] パット距離感

### 80切り
- [ ] パーオン後の 2パット率
- [ ] 距離別グリーンオン率
- [ ] ピンを狙うか中央を狙うか
- [ ] パットの傾斜読み
- [ ] スコアメイク戦略 (リスクリワード)
- [ ] メンタル (上がり3ホール)

旧 CSV にあった「打ち方ドリル」(チーピン治療、Pw スライス 等) は除外。
「打ち方は教えない」の方針に従い、必要なら `video_url` で外部リンクのみ。

## 課題タイプ別の埋め方ガイド

### skill (技術系) — 例: ショートパット、アプローチダフリ
- `practice_env`: home / putter-mat / range
- `practice_lv*`: 必須
- `course_criteria`: あり (例「直近3R で 1m 成功率 80%」)
- `drill_ids`: あり (自前アニメ化対象)

### mgmt (戦略系) — 例: クラブ選択ミス、OB 認知
- `practice_env`: `course-only` のことが多い
- `practice_lv*`: 空欄でよい
- `course_criteria`: 必須 (例「ハザード入水率 < 10%」)
- `drill_ids`: なし or「チェックリスト型ドリル」
- `video_url`: 解説記事へのリンク

### mental (精神系) — 例: 上がり3ホール崩れ
- `practice_env`: `course-only`
- `course_criteria`: 例「直近3R で 16-18番のスコア平均 が 1-15番より +0.5 以内」
- 自前ドリルというより、ラウンド前のルーティン提案

### knowledge (学習系) — 例: 持ち玉を決める
- `completion`: `one-shot`
- `practice_lv*`: 「自分の持ち玉を1行で書けた」のような認知系チェック
- `course_criteria`: なし or 後続課題の前提扱い
